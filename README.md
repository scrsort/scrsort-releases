# scrsort — downloads

scrsort is a minimal, privacy-first menu bar app for macOS: capture and annotate screenshots,
keep them in a searchable library (on-device text recognition), and share with opt-in public links.

**[Download the latest version](https://github.com/f4w4z/scrsort-releases/releases/latest)** · macOS 15 or later · Apple silicon and Intel

## Install

1. Download `Scrsort-<version>.dmg` from the latest release and open it.
2. Drag **scrsort** into **Applications**, then open it. It lives in the menu bar (viewfinder icon).

### First launch

Current builds are not yet notarized by Apple, so macOS blocks the first launch.
Open **System Settings › Privacy & Security**, scroll to the message about scrsort and
click **Open Anyway**. You only need to do this once per version.

scrsort asks for two permissions when they are first needed: access to your screenshot folder
(to import new screenshots) and Screen Recording (to capture). Nothing leaves your Mac unless
you choose to share a screenshot.

This repository only hosts release downloads.
